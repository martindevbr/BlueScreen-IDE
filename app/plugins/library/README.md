# Biblioteca de plugins

O catálogo dos servidores de plugins (os mesmos da aba Plugins) em cartões, com busca e favoritos. Os favoritos viram uma coleção em arquivo, para a equipe ter os mesmos plugins.

Importar uma coleção não instala nada: os plugins entram nos favoritos e você instala todos por um botão.

Veja [Biblioteca de plugins](../../../docs/AUTOMACOES.md#biblioteca-de-plugins).
